Sourcing backlog for the 328 genus profiles in `index.html`, generated
from the live dataset on 2026-07-15.

The wiki's front page credits the Natural History Museum Dino Directory, the
Paleobiology Database and "peer-reviewed literature". The first two are real and
well linked. The third is currently almost absent, and that is what this document
tracks.

**Only 3 of 328 profiles cite a paper.** Across all
556 citations in the collection, the overwhelming majority point at
the NHM Directory page, a PBDB taxon page, or a Wikimedia file page. Those are
catalogue entries and image credits — they are not the literature the claims rest on.

## How to read this

`Cites` counts every citation on the profile. `Primary` counts those resolving to a
journal or a DOI (`doi.org`, `10.xxxx/…`, Nature, Science, PLOS, Taylor & Francis,
Springer, Wiley, Cambridge, BioOne, PeerJ, eLife, Oxford Academic).

Genera are ranked by a `need` score, which adds weight for: no primary literature (+3),
a single citation (+3), AI-drafted prose (+2), a period/age conflict (+2), and one point
each for a missing independent summary, a disputed taxonomic status, a missing mass, and
no occurrence records. It is a work-ordering heuristic, nothing more.

Priority is not the same as importance. A famous genus with one citation still misleads
more readers than an obscure one, so weigh traffic alongside the score.

## Suggested approach

1. **Start with the description.** Every genus has an original description with an author
   and year. `sourceMeta.namedBy` / `sourceMeta.namedYear` already hold this for many, and
   247 profiles have no independent summary to fall back on.
2. **Add the reassessment where the profile leans on one.** Anything flagged `contested` or
   `nomen_dubium` is making a claim that needs a source.
3. **Mass estimates need their own citation.** 213 genera have no mass at all;
   any mass added should cite the study it comes from, not just appear.
4. **Prefer a DOI.** The `citations` array takes `{label, url}`; a `https://doi.org/…` URL
   is stable where a publisher link is not.
5. **Re-run the audit as you go.** Regenerate this file from the live dataset to watch the
   "profiles citing no primary literature" number fall.

## Note on the AI-drafted profiles

218 of 328 profiles have prose drafted by a language model from the
NHM and PBDB fields (`tools/generate_ai_profiles.py`). Since 2026-07-15 they are labelled as
such in the UI — a badge in the profile header and a disclosure in the Sources section — so
no reader mistakes them for reviewed text.

Labelling is a stopgap, not a fix. Every genus in Tier 1 and Tier 2 is a profile where a
model wrote confident prose and nothing in the citation list supports it. Verification is
the actual work; this file is the queue.
